# Support

Use [GitHub issues](https://github.com/alanslzrr/aesthc-diagram-lib/issues) for
reproducible bugs, feature requests and documentation questions. Search existing
issues first and include package version, React/framework versions, browser and a
minimal spec/reproduction. Remove confidential labels and customer information.

For private security concerns, follow [SECURITY.md](SECURITY.md). For conduct
concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Maintained by [Alan Salazar](https://github.com/alanslzrr). This is a volunteer
project; support is best-effort. General application development and layouts for
very large arbitrary graphs are outside the current scope.
