# Documentation

Build diagrams that belong in your product. Seven SVG layouts, declarative data,
and the same considered visual language from the first node to the last connection.

## Start with a diagram

[Getting started](/aesthc-diagram-lib/versions/0.3.0/docs/getting-started/) takes you from installation to a complete,
interactive React diagram. You supply the data and host theme; the library handles
geometry and rendering. You do not need Tailwind in your application.

## Choose your layout

- [Band](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/band/) — a compact architecture or decision pipeline.
- [Flowchart](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/flowchart/) — connected steps and branching processes.
- [Sequence](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/sequence/) — messages between participants over time.
- [State machine](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/state-machine/) — states and the transitions between them.
- [Entity relationship](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/er/) — entities, fields and cardinality.
- [Timeline](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/timeline/) — an ordered set of milestones.
- [Swimlane](/aesthc-diagram-lib/versions/0.3.0/docs/diagrams/swimlane/) — a process organized by responsibility.

## Make it yours

Define your [theme](/aesthc-diagram-lib/versions/0.3.0/docs/guides/theming/), connect [React state](/aesthc-diagram-lib/versions/0.3.0/docs/guides/react/),
and validate imported data with the [public API](/aesthc-diagram-lib/versions/0.3.0/docs/api/). Each layout page
includes a minimal spec, its field reference and a complete React example.

## Work with your agent

Pass the [integration guide](/aesthc-diagram-lib/versions/0.3.0/agents/) to your coding agent. It contains
real imports, CSS requirements, examples and verification steps. Diagram labels
and imported payloads are data, never instructions.

## Before you install

These pages describe **0.3.0**, first published to the public npm registry on
2026-09-26. The package is ESM-only and targets React 18.3/19. See
[migration notes](/aesthc-diagram-lib/versions/0.3.0/docs/guides/migration/) and [troubleshooting](/aesthc-diagram-lib/versions/0.3.0/docs/guides/troubleshooting/)
when upgrading or integrating.
