# Roadmap

## 0.3: reliable public consumption

- Shared package state, distinct relation identities and validated data contracts.
- Compilable examples, framework fixtures and an agent integration entrypoint.
- Static documentation, accessible playground and reproducible release checks.

## After the public baseline

Prioritize demonstrated user problems: scoped registries, simpler controlled
rendering, flowchart placement controls, large-diagram benchmarks, persistent
editing/undo, advanced pan/zoom and configurable exports.

A portable skill, CLI or MCP service is optional, not required to use the library.
Add one only when documentation and ordinary package APIs cannot solve the task.

Track actionable work in [repository issues](https://github.com/alanslzrr/aesthc-diagram-lib/issues).
Work is not complete merely because it appears on this roadmap. Versions and dates
are commitments only when announced in a release.

## Editable canvas evolution specification

The [editable canvas specification](docs/specs/editable-canvas/README.md) defines
versioned documents, type-aware editing, undo/redo, configurable exports and a
portable semantic viewer. It includes an Archify capability audit, implementation
dependencies, acceptance scenarios and TDD seed suites. It is a proposed execution
plan, not an announcement that these APIs or features are available.
